❓ Порядок пуска контура К-201 в работу

Порядок пуска контура К-201

Этап Действия и операции Ключевые параметры и оборудование
1. Прием сырья Подача легкой гидроочищенной нафты из секции гидроочистки (Н-105/1(2)) в емкость Е-201. Контроль уровня в Е-201 (20–80%), давления, отбор проб (АР-203). Уровень Е-201: 20–80% (сигнализация 19/81%, блокировка 8% — отключение Н-201/1(2)). Давление контролируется по поз. 320-PG-2512.
2. Настройка холодной циркуляции Переключение циркуляции сырья по схеме: Е-201 → Н-201/1(2) → Т-201 → К-201 → Н-202/1(2) → Т-201 → ХВ-201 → А-202/1,2 → Е-203. Контроль качества сырья после осушителей (влага ≤ 1,0 ppm). Расход по поз. 320-FIRCAL-3044 (не менее 39 м³/ч — сигнализация). Температура перед Т-201: поз. 320-ТIR-1011. После Т-201: 74–82 °C (поз. 320-ТIR-1017).
3. Вывод на горячую циркуляцию Подача сырья на 49-ю тарелку К-201. Включение насосов Н-201/1(2), Н-202/1(2). Запуск ребойлера Т-202 (подача пара НД через клапан 320-UZV-7016). Контроль температуры куба К-201 (90–110 °C, поз. 320-ТIR-1018), давления верха (≤ 0,289 МПа, поз. 320-PIRСАH-2011). Уровень куба К-201: 8–38% (сигнализация 8/38%, блокировка 4% — отключение Н-202/1(2)). Перепад по колонне ≤ 130 кПа (сигнализация).
4. Вывод на нормальный технологический режим Стабилизация параметров:
- Верх колонны: температура 65–75 °C, давление ≤ 0,289 МПа.
- Куб: температура 90–110 °C, уровень 8–38%.
- Орошение: расход 120–155 м³/ч.
- Контроль качества верхнего продукта (изопентановая фракция) и кубового продукта (деизопентанизированная фракция).
- Включение в работу всех контуров регулирования в автоматический режим.		 Все параметры поддерживаются в указанных диапазонах с помощью АСУ ТП. Сигнализации и блокировки по всем критическим параметрам активны для обеспечения безопасности и качества продукции.
